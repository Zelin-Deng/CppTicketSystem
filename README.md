# C++ 多线程售票系统

这是一个使用 C++ 实现的多线程售票系统学习项目。

项目从基础线程售票开始，逐步加入面向对象封装、互斥锁、请求队列、条件变量和生产者—消费者模型，用于学习操作系统中的线程同步与互斥知识。

## 当前版本

当前版本：**V2.0 请求队列与生产者—消费者模型**

V2 将原来窗口线程主动售票的模式，升级为用户提交购票请求、请求进入队列、窗口线程领取并处理请求的模式。

## V2业务流程

```text
用户提交购票请求
        ↓
请求进入 requestQueue
        ↓
condition_variable 通知窗口线程
        ↓
空闲窗口从队列领取请求
        ↓
检查库存
        ↓
生成票号
        ↓
扣减库存
        ↓
保存销售记录
        ↓
输出处理结果
